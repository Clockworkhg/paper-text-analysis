# Hardt-Mautner 1995 - CDA 与语料库语言学

- 原文件：`文献/vol6.pdf`
- 分类：核心方法论文献
- 阅读顺序：02
- 主题关键词：Critical Discourse Analysis、Corpus Linguistics、KWIC、media discourse

## 核心定位

这是一篇早期主张把语料库语言学引入批判话语分析的经典方法论文。它的价值在于说明：单靠 CDA 的小样本精读容易受研究者直觉限制，而语料库工具可以提供更系统的证据入口。

## 对本项目的用途

- 说明为什么需要工具，而不只是人工读新闻。
- 支撑 KWIC 和词频/搭配作为“进入话语结构”的技术手段。
- 为“研究级工具”的方法论必要性提供历史来源。

## 可写入论文的位置

- 文献综述：CDA 与 corpus 方法结合的早期脉络。
- 方法论：语料库技术如何弥补纯定性话语分析的局限。

## 阅读重点

重点看作者如何论证 CDA 与 corpus linguistics 的互补性，以及如何用语料库索引打破定量/定性边界。
