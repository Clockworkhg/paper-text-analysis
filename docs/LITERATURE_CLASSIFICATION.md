# 文献整理分类

本文档按“论文写作用途”而不是文件夹位置整理当前 `文献/` 目录中的 33 份 PDF。分类目标是服务本项目的研究级工具定位：语料库辅助话语研究（CADS）+ 批判话语分析（CDA）+ 搭配/语义韵 + 评价/框架分析。

## 1. 一类核心文献：必须精读

这些文献直接构成项目的方法论骨架，应优先阅读并进入论文“理论基础”和“研究方法”部分。

| 文献 | 类型 | 主要用途 | 建议使用位置 |
|---|---|---|---|
| `10.1177_0957926508088962.pdf` | 经典实证论文 | Baker 等将 CDA 与语料库方法结合分析英国媒体中的 refugees/asylum seekers/immigrants/migrants，是本项目最直接的方法模板 | 方法论、研究流程、定量与定性结合 |
| `vol6.pdf` | 方法论论文 | Hardt-Mautner 关于 CDA 与 corpus linguistics 的早期结合，说明为什么纯定性 CDA 需要语料库方法补充 | 理论缘起、方法合理性 |
| `语料库辅助话语研究的缘起、特征及应用_刘明.pdf` | 中文方法综述 | 解释 CADS 的缘起、特征和应用，适合作为中文论文中的核心理论支撑 | 国内外研究综述、方法框架 |
| `语料库与批判话语分析_钱毓芳.pdf` | 中文方法论文 | 说明词频、主题词、搭配、词丛、型式等如何服务 CDA | 方法说明、指标解释 |
| `国内基于语料库的批评话语分析研究综述_张瑞华.pdf` | 中文综述 | 梳理国内基于语料库的 CDA 研究，特别是新闻话语、媒体话语、国家形象等方向 | 国内研究现状 |
| `语料库文献/Patterns and Meanings in Di_...pdf` | CADS 专著 | Partington 等 CADS 理论与实践，适合作为“语料库辅助话语研究”的总框架 | 理论框架、方法名称 |
| `语料库文献/Using Corpora in Discourse_...pdf` | 方法专著 | Baker 的语料库话语分析方法入门，已 OCR 为文本 | 操作流程、语料库方法说明 |

|---|---|---|

| `语料库文献/Corups Concordance Collocat_...pdf` | KWIC、搭配、语料库基础概念 | Sinclair 相关版本/中英版，已 OCR，可辅助理解术语 |
| `10.1177_003368829302400207.pdf` | Sinclair 书评 | 快速了解 Corpus, Concordance, Collocation 的学术位置 |

| `语料库文献/Corpora in Applied Linguist_...pdf` | 语料库语言学总论 | Hunston 的语料库应用语言学，可支撑语料库研究的普遍方法论 |

## 7. 推荐阅读顺序

### 第一轮：建立方法论主线

1. `语料库辅助话语研究的缘起、特征及应用_刘明.pdf`
2. `语料库与批判话语分析_钱毓芳.pdf`
3. `10.1177_0957926508088962.pdf`
4. `vol6.pdf`
5. `语料库文献/Using Corpora in Discourse_...pdf`

目标：能清楚说明本项目不是普通词频统计，而是 CADS/CDA 框架下的语料库辅助话语研究工具。

### 第二轮：支撑具体算法与输出

1. `语料库文献/Corpus, Concordance, Colloc_...pdf`
2. `基于语料库和语料库驱动的词语搭配研究_卫乃兴.pdf`
3. `语义韵研究的一般方法_卫乃兴.pdf`
4. `语料库文献/Words and Phrases Corpus St_...pdf`
5. `词块的界定、分类与识别_马广惠.pdf`

目标：为 KWIC、搭配、修饰语、短语、语义韵等输出字段建立理论解释。

### 第三轮：连接媒体话语应用

1. `语料库文献/Discourse analysis and medi_...pdf`
2. `Muslims_BAAL-2010.pdf`
3. `语料库文献/News As Discourse. ...pdf`
4. `语料库文献/Discourse and Social Change_...pdf`
5. `国内基于语料库的批评话语分析研究综述_张瑞华.pdf`

目标：把工具应用到新闻媒体、国家形象、群体表征或议题框架研究中。

### 第四轮：补评价、情感和验证

1. `语料库文献/The language of evaluation_...pdf`
2. `10.1177_17506352241264197.pdf`

目标：说明工具输出如何进入评价资源、框架和验证流程，而不是直接把自动结果等同于结论。

## 8. 对应论文综述结构

可以按以下结构组织文献综述：

1. 话语研究与批判话语分析：Fairclough、van Dijk、中文 CDA 综述。
2. 语料库辅助话语研究：Hardt-Mautner、Baker、Partington、刘明、钱毓芳。
3. 搭配、KWIC 与语义韵：Sinclair、Stubbs、卫乃兴、McGee。
4. 媒体话语与表征研究：Baker/Gabrielatos/McEnery、Muslims/Islam 案例、国内国家形象研究综述。
5. 评价与框架分析：Martin & White、moral framing、情感语料库。
6. 自动化文本分析的可复现与验证：Text as Data、误差分析、人工复核。

## 9. 与当前工具模块的映射

| 工具模块 | 支撑文献组 | 需要在方法中说明的点 |
|---|---|---|
| Lexis DOCX 转 TXT | 语料库构建、CADS | 检索策略、语料来源、纳入排除标准 |
| 来源统计与机构合并 | 媒体话语、数据清洗 | 来源机构是话语生产位置变量；合并规则需要复核 |
| 国别识别 | 媒体来源分析、工具化验证 | 国别是辅助变量，需要置信度与人工校正 |
| KWIC 输出 | Sinclair、Baker、Stubbs | KWIC 是定性解释入口，不是单独结论 |
| 修饰语/短语提取 | 搭配、词块、语义韵 | 目标词周边表达是评价和表征线索 |
| 词性/翻译 | 语言处理辅助 | 自动结果需要抽样检查 |
| 研究方案文档 | CADS/CDA/Text as Data | 工具需要记录参数、版本、验证过程 |

## 10. 当前文献缺口

目前文献已经足够支撑“研究级工具”的核心框架，但如果要进一步增强论文说服力，可以后续补三类文献：

- 具体研究对象文献：例如研究 China、Global South、Ukraine、climate change 等，应补对应领域的媒体话语研究。
- 媒体系统比较文献：如果要比较英美、欧洲、亚洲或全球南方媒体，需要补 media systems / comparative media studies。
- 实体识别与数据清洗文献：如果强调机构合并和国别识别的技术贡献，可补 entity resolution、record linkage、knowledge base linking 方面文献。
