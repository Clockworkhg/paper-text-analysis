# 方法论说明

本项目定位为语料库辅助话语研究（Corpus-Assisted Discourse Studies, CADS）工具，服务于新闻/媒体语料中的话语表征、搭配模式、语义韵和评价资源分析。工具输出不被视为最终解释，而是帮助研究者定位可复核的语言模式。

## 理论框架

项目采用四层理论框架：

1. **语料库辅助话语研究（CADS）**：用语料库技术在大规模文本中发现反复出现的语言模式，再通过话语分析解释其社会意义。
2. **批判话语分析（CDA）**：将文本特征与话语实践、社会实践相连接，关注媒体文本中的表征、权力关系和意识形态。
3. **KWIC、搭配与语义韵**：通过关键词上下文、共现词和修饰语观察目标词的典型语境与评价倾向。
4. **评价理论与框架分析**：将形容词、短语和评价性表达视为立场、判断、鉴赏和议题框架的候选线索。

## 研究单位

- **文章**：LexisNexis DOCX 拆分后的单篇新闻文本。
- **来源机构**：新闻来源名，经过清洗、合并和规范化。
- **国别**：来源机构所属国家或地区，作为辅助分析变量，需要人工复核。
- **目标词**：研究对象，如国家、组织、人物、议题词。
- **KWIC 上下文**：目标词左右语境，是定性解释的入口。
- **搭配/修饰语/短语**：目标词附近反复出现的语言模式，是语义韵和评价资源的候选证据。

## 方法原则

1. 自动统计用于发现模式，不直接等同于研究结论。
2. 所有关键解释应回到 KWIC 或原文上下文复核。
3. 来源机构合并、国别识别、修饰语提取都应保留规则、参数和人工修正空间。
4. 输出应记录参数、运行环境和工具版本，以支持复现。
5. 研究报告中应说明自动处理的误差来源和人工复核方式。

## 第二阶段分析指标

- **KWIC**：为每个目标词命中保留左右上下文，作为语境化解释入口。
- **Collocates**：统计目标词窗口内的内容词共现候选，并输出近似 MI 和 log-likelihood 指标。指标用于排序候选，不直接证明话语意义。
- **SemanticProsodyCandidates**：用小型评价种子词表给出积极、消极、混合或未编码候选标签。该字段只提示潜在线索，最终语义韵必须通过 KWIC 复核。
- **GroupComparison**：按可选分组变量（原始来源表头、规范化媒体机构、国别、或研究者自定义映射如立场类别）分组汇总候选表达，用于观察不同媒体来源、国别或立场阵营的话语模式差异。分组变量属于研究设计决策，应在方法部分明确报告；国别标签属辅助推断，使用前需人工复核。

## 文献支撑

核心支撑来自 Baker et al.、Hardt-Mautner、Partington、Sinclair、Stubbs、van Dijk、Fairclough、Martin & White，以及刘明、钱毓芳、卫乃兴等中文研究。详细分类见 `docs/LITERATURE_CLASSIFICATION.md` 与 `docs/literature_notes/`。

## 方法限制

本工具不替代研究者解释。自动输出可能受到 OCR、分词、词性标注、机构名称歧义、知识库覆盖不足和语境窗口设置影响。因此，工具结果应被表述为“候选证据”“语言模式线索”或“辅助发现”，最终结论应结合人工复核和上下文分析。
